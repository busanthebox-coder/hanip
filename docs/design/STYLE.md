# 한입 스타일 가이드 (v5 — 프로덕트 톤 + 재질)

`docs/design/spec-v4.html`(14프레임)에서 도출하고 `docs/design/spec-v5.html`(8프레임)이 보완한 규칙이다.
**확정 시안은 홈 A·리빌 A.** 지시 27부터 모든 UI 작업의 게이트다 — 새 화면·새 컴포넌트는 여기에
맞춰 만들고, 리뷰는 여기로 한다.

v4는 장식을 걷어냈고 v5는 그 자리를 **재질**(종이 결·붓 잉크·도장)과 **구조**(판독 가능한 진행·
위계·실제 정보 밀도)로 되채웠다. **킬 리스트는 하나도 풀리지 않았다.** 색 토큰 값도 그대로다 —
바뀐 것은 사용 밀도뿐이다(§8·§9·§10).

---

## 1. 타이포 낙차

한 화면에 **지배 요소는 하나**다. 크기는 아래 계단에서만 고르고, 중간 크기를 새로 만들지 않는다.

| 역할 | 크기 | 굵기 | 색 |
|---|---|---|---|
| 히어로 (오늘의 단어·리빌 단어·스트릭 숫자) | 58~70px | 900 | `--ink` |
| 타이틀 (문제 예문·완료 문구) | 26px | 800~900 | `--ink` |
| 섹션 제목 / 본문 리드 | 15.5px | 650~850 | `--ink` / `--ink-2` |
| 메타 (상태·수치·캡션) | 12.5px | 650 | `--ink-3` |
| 보조 라벨 (한국어 보조·영어 보조) | 11.5px | 650 | `--ink-3` |

- 예외는 스펙 프레임이 직접 지정한 값만 (레슨 덱 패턴 44px, 단어 상세 표제어 52px, 어순 타일 27px 등).
- 학습 콘텐츠(한국어 문장·형태)는 이 계단 위에 얹는 히어로다 — 20~31px 구간은 예문 전용.

## 2. 구획

- **여백과 1px `--line`만으로 끊는다.** 배경 블록·둥근 박스로 그룹을 만들지 않는다.
- **카드 윤곽은 화면당 0~1겹.** 카드 안의 카드 금지(책장 3중 중첩이 이 규칙이 생긴 이유다).
- 플레이어의 덱(카드 겹침)은 1겹으로 친다 — 그 안쪽은 전부 선 행이다.
- 리스트는 `border-top: 1px solid var(--line)` 행, 마지막 행만 `border-bottom`.

## 3. 색 예산

- 바탕은 무채색(`--bg --card --wash --ink*`)이고, **화면당 포인트색은 최대 2개**다.
- `--accent` = 주 버튼(CTA) 하나. 라벨·키커·칩에 쓰지 않는다.
- `--gold` = 진행(그릇·트랙·도장)과 타깃 어절 밑줄. 절제해서 쓴다.
- `--good` = 정답 순간. `--bad` = 오답 글자 자체에만(배경·테두리로 번지지 않는다).
- 토큰 값은 바뀌지 않는다. 바뀌는 것은 **사용 밀도**뿐이다. 리터럴 색 금지(`scripts/hardcoded-colors.test.js`가 감시한다).

## 4. 킬 리스트 (하면 안 되는 것)

1. **「A · B」식 두 언어 병기 도장** — 두 언어는 항상 줄바꿈 위계다. (§6)
2. **uppercase 마이크로 라벨** — `text-transform: uppercase` + `letter-spacing: .1em~.2em` 키커.
   섹션 제목은 15.5px 문장형(`Mistakes`, `In use`, `Forms`)이나 11.5px `--ink-3` 한 단어로 쓴다.
3. **라벨 캡 콜아웃** — 색 좌측 바(`border-left: 3px solid`) + 캡 라벨 박스. 뉘앙스·해설은
   선 하나 아래 **영어 본문 문단**으로 흐른다.
4. **파스텔 칩 남발** — 필터·레벨·품사·상태를 pill로 두르지 않는다. 필터는 밑줄 탭,
   상태는 글리프 한 자(`✓` good, `★` gold), 메타는 `--ink-3` 한 줄.
5. **이모지 전면 금지** — 앱 소스의 이모지는 **0개다(탭바 포함)**. 지시 28이 탭바의 마지막
   5개(🍚 📚 가 學 📖)를 직접 그린 SVG로 교체했다(§9). 상태는 타이포 글리프 한 자(`✓` `★` `☆` `✕`)로만
   표시한다 — 이건 이모지가 아니라 본문 폰트의 기호다.
6. **점선 테두리** — `border-style: dashed`로 "미완/임시"를 표현하지 않는다. 낮은 대비로 낮춘다.
   (예외: 어순 카드의 미탐색 형태소 밑줄 — 탭 어포던스로만.)

## 5. 유지해야 하는 자산

- 종이 재질 — 격자 2겹 + 3px 도트 결. 앱 전역이다(§10).
- 그릇 메타포 — 단일 컴포넌트가 모든 크기를 그린다(§8).
- 수집 도장 — `transform: rotate(-8deg)`, `--gold` 테두리, "한입" 글자.
- 기존 색 토큰 값, 44px 최소 탭 타깃, `word-break: keep-all`, 진짜 `<button>`, 명시적 transition.

## 6. 언어 위계 (tab-contract.md와 동일 규칙)

학습자는 **한국어를 배우는 영어 화자**다.

1. **학습 콘텐츠**(단어·예문·대화·문법 형태·타일·토큰·로마자) → 한국어가 히어로. 크게, 지배적으로.
2. **설명·해설·뉘앙스** → 영어 본문(실데이터 영어 원문 그대로). 번역하지 않는다.
3. **기능성 UI 문자열**(버튼·상태·섹션 제목·탭·필터·메타·통계) → 영어 메인 + 한국어 11.5px 보조,
   **줄바꿈**으로 분리. 한국어 보조는 생략 가능(짧은 상태 문구·수치는 영어만).
4. **학습 지시문**(「무슨 뜻일까요?」류) → 한국어 유지 + 그 아래 작은 영어 보조.
5. `A · B` 한 줄 병기는 **금지**.

```html
<!-- 금지 -->
<button>시작 · Start →</button>

<!-- 권장 -->
<button><b>Start</b><i>시작하기</i></button>
```

## 7. 컴포넌트 프리미티브

- **CTA**: `--accent` 배경, `box-shadow: 0 3~5px 0 var(--accent-deep)`, 눌리면 내려앉는다.
  영어 17px + 한국어 10.5px(opacity .62).
- **선택지 행**: pill이 아니라 `border-top: 1px solid var(--line)` 행. 좌우로 카드 패딩만큼
  내밀어(`margin: 0 -22px; padding: 9px 22px`) 화면 폭을 다 쓴다. 선택된 행은 `--wash` 배경.
- **필터**: 밑줄 탭 — 선택된 것만 `border-bottom: 2px solid var(--ink)`.
- **시트**: `--bg` 배경, 상단만 라운드, `--shadow-2`, 스크림은 `--ink` opacity .2~.36.

## 8. 그릇 — 컴포넌트 하나뿐 (지시 28)

그릇은 앱이 반복하는 유일한 은유다. **패스는 저장소에 한 벌만 존재한다.**

- 기하는 `src/lib/bowl.js`(순수 함수·상수), 렌더는 `src/components/Bowl.svelte` **하나**다.
  화면에 SVG를 복붙하면 안 된다 — 이 규칙이 생긴 이유는 v4에 그릇 사본이 3개(홈 44px 선 아이콘,
  승리 110px, 온보딩 108px) 있었고 셋이 서로 다른 모양이었기 때문이다.
- 구성: **가변 두께 잉크 리본(몸통) + 붓 획 전(rim) + 굽(foot)**. 굽이 있어야 컵이 아니라
  밥그릇으로 읽히고, 전이 있어야 유기그릇의 인상이 난다. 밥은 `--gold` 하나 — 알갱이도 하이라이트도 없다.
- `fill` prop은 0~1이고 밥 표면은 `y = 72 - 42 × fill`(viewBox 100 기준)로 직선 대응한다.
  **0%는 형상 분기다** — 높이 0의 사각형이 아니라 밥 도형을 아예 그리지 않는다.
  **100%는 고봉** — 밥이 전을 넘고 전 획이 그 위를 가로지른다. 「고봉」 자체가 목표 달성 신호이므로
  김·반짝임 같은 장식은 얹지 않는다.
- **광학 보정**: 60px↑ 무보정 / 24~59px `sm`(ink stroke 2.6·foot 7.6) / 24px↓ `xs`(4·9.5).
  패스를 바꾸지 않고 채움 도형에 stroke만 얹는다.
- 탭바 크기(23px)에서는 같은 실루엣을 선으로 축약한 `variant="line"`을 쓴다 — 채움 잉크 덩어리는
  나머지 네 아이콘과 광학 밀도가 맞지 않는다. 이 변형도 같은 컴포넌트 안에 있다.
- 현재 사용처: 승리 112 · 온보딩 108 · 홈 86 · 주간 26 · 탭 23(line).

## 9. 아이콘 — 하나의 그리기 시스템 (지시 28)

- 탭 아이콘 5종은 `src/components/TabIcon.svelte` 하나가 그린다:
  **그릇 / 책등 3개 / 가 / 文 / 펼친 책**.
- 규격: 24×24 viewBox, `fill: none`, `stroke: currentColor`, **stroke-width 1.7**, round cap·join.
  획 밀도가 높은 **文만 1.55**로 보정한다. 선택 상태는 `--accent-deep` 색 하나만 바뀐다.
- 한글은 폰트 글자가 아니라 **획**으로 그린다(ㄱ 2획 + ㅏ 2획) — 그 탭이 「글자가 어떻게
  만들어지는가」임을 형태가 말한다.
- 한자는 **文**(4획)이다. **學(16획)은 쓰지 않는다** — 23px에서 위쪽 다섯 획이 한 덩어리로 뭉개지고,
  획을 쳐내 단순화하면 `学`(일본 신자체)이 되어 한국어 앱에서 틀린 글자가 된다.
- Today 아이콘은 그릇 컴포넌트다(§8). 은유가 탭바까지 내려온다.

## 10. 종이 결 (지시 28)

- `--study-grid` **토큰 값은 건드리지 않는다**(라이트 4.5%·다크 3.5%). 대신 **같은 선을 2겹**으로 깔아
  실효 대비를 약 2배로 올리고, 그 위에 **3px 도트 격자**를 얹어 종이의 결(tooth)을 만든다.
- 결은 `<html>`에 칠한다 — 캔버스로 전파되므로 어떤 화면도 빈 흰 판으로 남지 않는다.
- **결은 카드 안쪽까지 잇는다**(`.tooth`: `--card` 바탕 + 같은 3px 도트). 이게 없으면 카드는
  책상 위의 낱장이 아니라 종이 위에 얹힌 흰 사각형으로 읽힌다.
- 덱 뒷장은 각각 **-0.35° / +0.5°** 어긋난다 — UI 스택이 아니라 흐트러진 종이 더미.

## 11. 진행 표시 — 3상태 (지시 28)

미세한 원을 개수만큼 늘어놓지 않는다. 팔 길이에서 읽히지 않는다.

| 상태 | 표시 |
|---|---|
| 완료 | 한입 도장(24px, `--gold`, `rotate(-8deg)`) |
| 진행 중 | `5/8` + 38px 바(`--progress-track` 트랙 · `--gold` 채움) |
| 미착수 | 흐린 `0/8` + 빈 트랙 (`--ink-3`, weight 700) |

주간 스트립도 pip이 아니라 **실제로 차오르는 26px 그릇 7개**다(§8).

⚠️ **클래스명**: 진행 바는 `.progbar`다. `.bar`는 플레이어 상단 레일(`.playbar`로 개명)이 이미 쓰던
이름이라 충돌하면 3px 바가 34px 원으로 렌더된다. 책장 부속 행은 `.subrow`다 — `.sub`는 리빌 보조문이
쓴다. **컴포넌트 스코프를 넘는 이름을 새로 만들지 마라.**
