한입 디자인 보완 시안 v5 — 재질과 구조를 되채우기

v4의 규율(킬 리스트)은 하나도 풀지 않는다. 대신 v4가 덜어내면서 같이 빠져나간 재질(종이 결·붓 잉크·도장)과 구조(실제 정보 밀도·판독 가능한 진행·위계)를 되채운다. 색 토큰 값은 한 글자도 바꾸지 않았고, 바뀐 것은 사용 밀도뿐이다.

더한 것 1 — 붓 그릇44px 선 픽토그램을 폐기하고 전(rim)·몸통·굽(굽)을 가진 가변 두께 잉크 실루엣으로 교체. 밥은 --gold, 100%는 고봉으로 전을 넘는다.
더한 것 2 — 종이 결--study-grid 값은 그대로, 같은 선을 2겹으로 깔아 실효 대비를 2배로. 여기에 3px 도트 결을 얹고 카드 안쪽까지 이어 붙였다.
더한 것 3 — 판독 가능한 진행8개 미세 원 → n/8 숫자 + 38px 바. 완료 챕터는 숫자 대신 한입 도장.
더한 것 4 — 정보로 채운 여백홈 A는 오늘 만날 실제 단어 6개, 홈 B는 72과 안의 내 위치(코스 척추). 카드로 때우지 않는다.
더한 것 5 — 커스텀 탭 아이콘이모지 5종 폐기. 그릇·책등·가·文·펼친 책을 같은 획 두께로 직접 그렸다.
