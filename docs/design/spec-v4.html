한입 디자인 샘플 v4 — 영어 설명 위계

v3의 레이아웃·타이포 낙차·색·프레임 구성을 1px도 건드리지 않고 언어 위계만 뒤집었습니다. 학습자는 한국어를 배우는 영어 화자입니다. 배우는 대상인 한국어(단어·예문·대화·문법 형태)는 히어로로 남고, 설명·뉘앙스·버튼·상태·섹션 제목은 영어가 본문입니다.

타이포 낙차화면당 지배 요소 하나 — 58~70 / 26 / 15.5 / 12.5 / 11.5px. 중간 크기를 두지 않습니다.
색 예산무채색 + 상태 포인트 최대 2색 + 주 버튼 accent 하나. 골드=진행·타깃, good=정답, bad=오답.
구획1px 선과 여백만. 카드 윤곽은 화면당 0~1겹, 중첩 없음.
언어 위계설명·기능 문자열은 영어가 본문, 한국어는 11.5~12.5px ink-3 보조. 병기 점(·) 없이 항상 줄바꿈.
