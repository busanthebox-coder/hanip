# 지시 03 — A2 콘텐츠 감사·교정 (챕터 12–34)

## 목표
`docs/harness/audit-protocol.md`를 A2 23개 챕터 전부에 실행한다. A1에서 78건이 나왔다 —
A2는 챕터가 2배가 넘고 문법이 어려우니 **더 나온다고 가정하고** 시작하라.

## 작업
1. 프로토콜 문서를 정독한다. 결함 5종의 실례가 전부 거기 있다.
2. 챕터를 4~5개 묶음으로 나눠 진행: 덤프 → 전 카드 정독 → 발견 기록 → 수정 → 재컴파일 확인.
3. 수정 경로 (프로토콜의 심각도 정책 그대로):
   - guess 모호 → `data/overrides.json` guessDistractorBans (양방향)
   - hunt 오적중 예문 → huntExampleBans / 컴파일러 버그면 테스트 먼저
   - payoff 오하이라이트 → payoffBans / 규칙 구멍이면 컴파일러
   - 사실 오류 → 데이터 수정 + `docs/harness/DATA-CHANGES.md` 기록
     (파일이 없으면 생성: 날짜·파일·바꾼 문자열 전/후·사유·부모 저장소 해당 여부)
4. 묶음마다 `npm run guard` — overrides가 A1 카드를 바꾸면 baseline이 알려준다.
   그 금지가 A1에도 옳으면(같은 혼동쌍) 드리프트 목록 명시 후 재스냅샷 허용.

## 검증
```bash
npm run guard
ls docs/harness/audit/chapter-{12..34}.json | wc -l   # 23
node -e 'const fs=require("fs");let b=0,t=0;for(let n=12;n<=34;n++){const a=JSON.parse(fs.readFileSync(`docs/harness/audit/chapter-${n}.json`));for(const f of a.findings){t++;if(f.severity==="blocker"&&!f.fixed)b++}}console.log("findings",t,"unfixed blockers",b)'
```

## 완료 기준
- audit JSON 23개 전부 존재, **미수정 blocker 0**
- guard 그린, PROGRESS 03행에 발견/블로커/overrides 추가 수 기록
- 배포는 아직 금지 (예산 미해결) — 지시 04에서 한다
