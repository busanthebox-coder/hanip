# 지시 18 — 스트릭·주간 히트맵·문법 카드 수집·별표

## 목표
쌓이는 게 보이게 한다: 연속 일수, 일주일의 발자국, 모은 문법 카드, 저장한 단어.

## 작업
1. **스트릭**: `src/lib/stats.js` — bowls 맵에서 파생(`streak()`: 오늘 또는 어제부터
   연속으로 bowls[day] ≥ 1인 일수. 오늘 아직 0이어도 어제까지 이어졌으면 유지 표시,
   "오늘 한 입이면 N+1일" 문구). dailyGoal(prefs) 반영: 그날 목표 달성 여부
   `goalMet(day)`. 단위 테스트 4+ (연속/끊김/오늘 미학습/목표 2입).
2. **홈 개편(소폭)**: 그릇 옆에 🔥 N일 · streak. 그 아래 주간 히트맵 7칸(월~일):
   빈칸/한입1(반그릇)/목표달성(꽉참) 3단계, 오늘 테두리. 탭하면 그날 입 수 토스트.
3. **문법 카드 수집**: 문법(pattern) 한입 완료 시 그 문법이 "수집됨" —
   store에 `collected: [biteId]` 추가(markBiteDone에서 kind==='pattern'이면 기록).
   책장 상단에 `📜 모은 문법 N/236` 진입 → `GrammarCollection.svelte`:
   수집 카드 그리드(문법 이름 + 도장 🔴 낙관 스타일 + 챕터·레벨), 미수집은 실루엣.
   탭하면 해당 문법 한입 재생(복습 동선). 이미 완료한 문법 한입은 소급 수집
   (첫 로드에 done 맵에서 재구성 — 마이그레이션 함수 1개, 테스트 1개).
4. **별표 저장 + 단어장 링크**:
   - GuessCard reveal에 ☆(44px) — store `starred: [ko]` 토글.
   - reveal 하단 `단어장에서 자세히 · See in wordbook →` — 단어장 탭으로 이동해
     해당 단어 상세 자동 오픈(App에 간단한 딥링크 상태 하나면 된다. 라우터 도입 금지).
   - 단어장 필터에 `⭐ 저장한 단어 Starred` 추가.
5. **승리 화면**: 스트릭 줄(🔥 6일째) + 문법 한입이면 `📜 문법 카드 획득!` 라인.

## 검증
```bash
npm run guard:full   # stats 테스트 포함
```
dev: 이틀치 bowls 시드 → 스트릭·히트맵 → 문법 한입 완주 → 수집 그리드에 도장 →
기존 완료분 소급 확인 → 단어 별표 → 단어장 Starred 필터 → 딥링크 상세 오픈.
