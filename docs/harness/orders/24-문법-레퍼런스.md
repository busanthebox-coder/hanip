# 지시 24 — 문법 레퍼런스 뷰 (23 완료 후 실행)

## 배경
자습 완결성 검증(2026-08-03)에서 확인된 마지막 구멍: 배운 문법을 **다시 보는** 길이
'한입 통째 재생'뿐이다. "은/는 표만 30초 다시 보고 싶다"가 자습의 일상인데,
수집 그리드(지시 18)의 카드를 탭하면 재생만 된다.

## 목표
수집 그리드의 문법 카드 탭 → **정적 규칙 시트**(열람) → 원하면 재생. 컴파일 무변경,
UI만. (21이 만든 more.funcLead·more.pitfall을 여기서 소비한다.)

## 작업
1. `GrammarRefSheet.svelte` 신설 — 바텀시트(설정 시트 패턴 재사용):
   - 이름 · sub · **funcLead**(펼치면 func 전문)
   - 형태 표(rows 전체)
   - 예문: 그 노트의 examples **전부**(컴파일 카드가 hunt 2개만 담고 있으면 부족 —
     bites의 해당 pattern 바이트에서 hunt.lines + 드릴/어순 카드의 원문을 합쳐 보여주되,
     중복 제거. 데이터를 새로 뽑지 말고 컴파일 산출 안에서 조립하라)
   - keyPoint · pronunciation · **pitfall**(✗/✓ 두 줄 + explanation)
   - 하단 버튼 2: `한입 다시 풀기 · Replay bite` / `닫기 · Close`
   - 전부 이중 언어, 토큰만, TTS 도트는 예문에.
2. `GrammarCollection`: 카드 탭 = 시트 열기(재생은 시트 안 버튼으로 이동).
   미수집 카드 탭도 시트는 열리되 상단에 `아직 안 배웠어요 · Not learned yet` 배지.
3. 접근 경로 하나 추가: 문법 한입 **승리 화면**의 "문법 카드 획득!" 줄을 탭하면
   방금 그 문법의 시트가 열린다(복습 동선 단축).

```bash
npm run guard:full   # 컴파일 무변경 — baseline·additive 개념상 그대로여야 함
```

미수집 카드 시트 배지 / 승리 화면에서 시트 진입.
