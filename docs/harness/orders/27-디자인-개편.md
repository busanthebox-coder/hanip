# 지시 27 — 디자인 개편: 프로덕트 톤 + 영어 메인 언어 위계

## 근거와 스펙
- **디자인 스펙 = `docs/design/spec-v4.html`** (14프레임 목업 — 이 파일이 곧 시안이다. 브라우저로
  열어 프레임별로 대조하며 작업하라). 토스·산타·케이크 실물 관찰에서 도출했고 사용자가 승인했다.
- **확정 시안: 홈 A**(오늘 배울 단어 히어로) · **리빌 A**(단어 58px 각인형). B안 프레임은 참고용.
- 이 지시는 **UI 전용**이다. 컴파일 산출(bites·index·snacks·wordbook 등 데이터 파일)은 1바이트도
  변하면 안 된다 — baseline·check-additive·컴파일 산출 해시가 증인.

## 언어 정책 개정 (tab-contract 개정 — 이 지시에서 문서도 고친다)
`docs/tab-contract.md`의 "한국어 · English 병기" 규칙을 다음으로 **교체**하고, 개정 이력을 남겨라:
1. 학습 콘텐츠(단어·예문·대화·문법 형태·타일·토큰·로마자)는 **한국어가 히어로** — 크게, 지배적으로.
2. 설명·해설·뉘앙스는 **영어 본문**(실데이터 영어 원문 그대로).
3. 기능성 UI 문자열(버튼·상태·섹션 제목·탭·필터·메타·통계)은 **영어 메인 + 한국어 11px 보조**(줄바꿈).
4. 학습 지시문(「무슨 뜻일까요?」류)은 한국어 유지 + 작은 영어 보조.
5. **「A · B」식 두 언어 병기 도장 금지** — 두 언어는 항상 줄바꿈 위계.

## 스타일 가이드 신설 — `docs/design/STYLE.md` (이 지시에서 작성)
스펙에서 도출된 규칙을 명문화(향후 모든 지시의 게이트):
- 타이포 낙차: 58~70 / 26 / 15.5 / 12.5 / 11.5px — 중간 크기 금지. 화면당 지배 요소 1개.
- 구획은 여백과 1px `--line`만. 카드 윤곽 화면당 0~1겹(카드 중첩 금지).
- 색 예산: 무채색 + 화면당 포인트색 최대 2(정답 순간 good, CTA accent, gold 절제).
- 금지: 색 좌측 바+라벨 캡 콜아웃, uppercase 마이크로 라벨, 파스텔 칩 남발, 이모지(탭바 글리프 제외).
- 유지: 격자 종이 배경, 그릇 메타포, 수집 도장(-8° 회전, gold), 기존 색 토큰 값.

## 작업 B — 메커니즘 3종 (전부 런타임 전용, 테스트 선행)
1. **SRS 다음 간격 표시**: guess 정답 리빌 하단에 ink-3 한 줄 "Next review in N days"(+한국어 보조).
   `srs.js`에 다음 간격 계산 헬퍼(현재 rung 기준, record와 동일 로직 재사용) + 단위 테스트 2
   (첫 정답→1일 또는 3일, 오답 후→리셋 값. 실제 INTERVALS 상수와 정합 확인).
2. **오답 노트**: 승리 화면에 세션 중 틀린 카드 목록(문제/정답/해설, 산타 톤 — 스펙 프레임 9).
   BitePlayer의 오답 기록에서 수집하는 순수 함수 분리 + 단위 테스트 2(오답 0이면 섹션 미노출,
   재출제 후 맞혀도 "틀렸던 카드"로 집계). 복습(워밍업) 카드 오답도 포함할지는 포함으로 — 사유 기록.
3. **홈 그릇 진행**: 오늘 완료 바이트 수 기반 그릇 채움(스펙 프레임 1의 소형 그릇). 기존
   `bowls`/`weekBowls` 데이터 재사용 — 새 저장 필드 금지.
