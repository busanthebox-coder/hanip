# 지시 28 — 재질·구조 복원 (v5 보완)

## 근거
지시 27(v4)이 장식을 걷어냈지만 그 자리를 채우지 않아 실물이 앙상해졌다. 감독자가 라이브에서
결함 7개를 실측했고, v5 시안이 그것을 겨냥해 만들어졌다. **되돌리는 작업이 아니다** — v4의
킬 리스트를 그대로 지키면서 **재질(material)과 구조**만 더한다.

- **디자인 스펙 = `docs/design/spec-v5.html`** (8프레임. 코드를 읽으면 치수·패스가 전부 있다)
- **확정: 홈 A안** (오늘 만날 단어 6개 + canDo + 86px 그릇) · **한자 탭 아이콘 文** (學은 16획이라
  23px에서 뭉개지고, 획을 쳐내면 일본 신자체 学이 되어 한국어 앱에서 틀린 글자가 된다)
- 나머지(진행 표시·책장 위계·종이 결·잉크 번짐·승리 화면 다음 안내)는 사용자가 일괄 승인.
- `docs/design/STYLE.md`의 킬 리스트와 언어 정책(영어 메인·한국어 보조·병기 도장 0)은 전부 유효.

## 고칠 결함 7개 (라이브 실측)
1. 홈 500px 세로 공백 — 여백이 아니라 미완성으로 읽힘
2. 그릇 은유가 44px 선 아이콘으로 축소 (승리 화면 110px만 살아 있음)
3. 진행 표시 판독 불가 — 챕터 행 8개 미세 원, 주간 7개 동일한 빈 그릇
4. 책장 위계 역전 — 간식 행(채운 배경)이 본편 챕터 행보다 무거움
5. 챕터 목표 한 줄 잘림("…")이 고장으로 보임
6. 종이 재질 비활성 — 격자 4.5%는 안 보이고 카드는 흰 사각형
7. 탭바만 이모지 — 정제된 타이포와 충돌

## 작업

### A. 그릇을 공용 컴포넌트로 (결함 2·3)
v5의 붓 획 그릇(몸통 리본 + 전 + **굽**)을 **단일 SVG 컴포넌트**로 만들고 132/86/44/23px에
같은 패스를 쓴다(작은 크기 광학 보정은 v5 방식대로 채움 도형에 stroke). 채움은 0~100% prop,
100%는 고봉(밥이 전을 넘고 전 획이 그 위를 가로지름). 승리 화면·홈·주간·탭 아이콘이 전부
이 컴포넌트를 쓴다 — 사본 금지. 단위 테스트 2(채움 0%·100% 형상 분기, 크기별 stroke 보정).

### B. 홈 A (결함 1·2)
오늘 한입에서 만날 단어를 **뜻 없이 한국어만** 노출(추측 설계를 깨지 않는다 — v5 근거),
canDo 문장, 86px 그릇. 데이터는 `bites.json`이 이미 가진 것만 꺼내 쓰고 새 필드·새 저장 금지.

### C. 진행 표시 3상태 (결함 3)
완료=한입 도장 / 진행 중=`5/8` + 38px 바 / 미착수=흐린 `0/8`. 주간도 실제로 채워지는 그릇 7개.

### D. 책장 (결함 4·5)
간식 행의 채운 배경을 빼고 들여쓰기·얇은 선·작은 라벨로 종속. 챕터 목표는 2줄 허용(잘림 해소).

### E. 종이 재질 (결함 6)
`--study-grid` **토큰 값은 건드리지 말고** v5 방식(같은 선 2겹 + 3px 도트 결)으로 실효 대비를
올리고, 결을 **카드 안쪽까지** 잇는다. 덱 뒷장 미세 회전(-0.35°/+0.5°)으로 흐트러진 종이 감각.

### F. 탭 아이콘 5종 (결함 7)
이모지 제거 → 24×24 stroke 1.7 round cap currentColor SVG: 그릇 / 책등 3개 / 가(획으로) /
**文** / 펼친 책. 하나의 그리기 시스템으로.

### G. 모션·마감
정답 시 잉크 번짐 1종(과하지 않게). 승리 화면 하단 공백에 다음 항목 안내 행(실데이터).
플레이어의 짧은 덱은 세로 중앙 배치(홈과 같은 병이 플레이어에도 있다 — v5 관찰).

## ⚠️ 클래스명 충돌 (v5 제작 중 실제로 터진 것 — 이식 시 재발 주의)
- `.bar` — 플레이어 진행바와 새 진행 모듈이 충돌해 3px 바가 34px 원으로 렌더됐다
- `.sub` — 책장 행과 리빌 뉘앙스 보조문이 충돌해 보조문이 flex 32px 들여쓰기로 깨졌다
