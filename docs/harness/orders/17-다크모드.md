# 지시 17 — 다크 모드

## 목표
밤의 학습자를 위한 두 번째 옷. 먹지에 쓴 한지 느낌 — 단순 반전 금지.

## 작업
1. `tokens.css` 토큰 이중화: `:root`는 현행(밝음). 다크 팔레트는 **의도된 디자인**으로:
   - 배경 #17150F(먹지) · 카드 #201D15 · wash #2A2618 · 라인 #383325
   - 잉크 #EDE6D6 · ink-2 #B5A98F · ink-3 #8C8168
   - 액센트(고추장)는 채도 유지하되 밝기만 +6% (#F0603A 근처) — 어두운 바탕에서
     탁해지지 않게. 금색·청자색도 동일 원칙. 그림자는 투명도 상향.
   적용: `@media (prefers-color-scheme: dark)`에 토큰 재정의 +
   `:root[data-theme="dark"]` / `:root[data-theme="light"]`가 미디어쿼리를 이긴다.
2. prefs.theme(자동/밝게/어둡게)를 App 최상위에서 `document.documentElement.dataset.
   theme`로 반영 (auto면 속성 제거).
3. **하드코딩 색 소탕**: `grep -rn "#[0-9A-Fa-f]\{3,6\}" src/components src/styles`로
   토큰 밖 색을 전수 조사 — 특히 챗 말풍선 노랑(#FCE879)·간식·리더에 남아 있다.
   전부 토큰화(필요하면 `--chat-bubble` 등 신규 토큰). 예외는 흰 글자 on 액센트뿐.
4. `<meta name="theme-color">`를 테마에 따라 JS로 갱신(설치 앱 상단바 색).
5. DesignShowcase가 있으니 거기에 다크 스위처를 붙여 전 컴포넌트 육안 점검에 쓰라.

## 검증
```bash
npm run guard:full
grep -rn "#F[Cc][Ee]879" src/ | wc -l   # 0이어야 함 (말풍선 토큰화 증거)
```
Playwright/dev: 설정 어둡게 → 홈/한입(전 카드종)/책장/단어장 상세/클러스터/리더/
한글/한자 순회 스크린샷 — 대비 뭉개짐·흰 섬광 박스 없는지. 자동 모드가 OS 설정 따라감.
