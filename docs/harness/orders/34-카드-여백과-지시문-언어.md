# 지시 34 — 카드 화면의 세로 배분과 A1 지시문 언어

## 근거

라이브(order 33 배포본, 375×812) 실측 진단 2건.

**1. 카드 화면의 세로 배분이 무너져 있다.** `.deck`가 `margin: auto 0`로 세로 중앙에 놓여
있어 한 화면 안에서 레이아웃이 양극단으로 요동친다.

| 상태 | 위 여백 | 카드 높이 | 카드→CTA | 결과 |
|---|---|---|---|---|
| 답변 전 | 210px | 344px | 138px | 빈 공간이 화면의 43% |
| 답변 후 | 48px | 691px | −30px | sticky CTA가 카드를 30px 덮음 |

답변 후에는 `See this word in the wordbook →`(bottom 716)가 CTA(top 709) 밑에 깔려
하단부가 눌리지 않는다. 짧은 카드는 허공에 뜨고 긴 카드는 버튼에 부딪힌다.

**2. A1 학습자가 못 읽는 언어가 지시문의 1순위다.** 계약 규칙 4는 학습 지시문을
한국어 메인 + 영어 보조로 못박았는데, 1~11과는 한글을 **가르치는 중인** 구간이다.
읽을 수 없는 지시문은 몰입이 아니라 공백이다.

**3. 한국어 단독 UI 문자열 3개** — 계약 규칙 3(기능성 UI = 영어 메인 + 한국어 11.5px 보조)
위반. `BitePlayer.svelte`의 복습 안내 1개, `Home.svelte`의 그릇 안내 3분기.

## 작업

### A. 재생 화면을 한 뷰포트로 (진단 1)
- `.bp.playing`은 `height: 100dvh`. 승리 화면은 접히지 않아야 하므로 `.bp` 기본값
  `min-height`는 그대로 둔다 — `playing` 클래스로만 고정한다.
- 새 `.stage`가 playbar와 CTA 사이에서 **스크롤을 소유**한다(`flex:1; overflow-y:auto`).
  CTA가 스크롤 영역 **밖**으로 나가므로 겹침이 구조적으로 불가능해진다.
- `.deck`는 `margin: auto 0` → `flex: none`. 카드는 내용 높이를 유지한 채 스테이지 위쪽에
  붙는다. 스테이지를 꽉 채우면(`flex:1`) 텅 빈 긴 종이가 되고 뒷장 스택이 가려진다.
- `.nav`의 sticky와 그라데이션 페이드를 걷는다 — 충돌을 가리던 장치였다.

### B. A1 지시문은 영어가 이끈다 (진단 2)
- 새 `src/lib/instructions.js` — `biteLevel(bite)` / `instructionLead(level)`.
  판정은 **컴파일 산출이 아니라 런타임**에서 한다: 레벨은 학습자의 위치이지 카드의 성질이
  아니고, 컴파일러에 넣으면 UI 결정이 얼어붙은 `bites.json`으로 들어간다.
- `BitePlayer`가 바이트 열 때 한 번 계산해 `GuessCard`·`HuntCard`·`OrderCard`에 넘긴다.
  워밍업이 다른 챕터에서 끌려와도 **학습자가 연 바이트**를 따라간다.
- 짝은 절대 깨지 않는다 — 순서와 두 글자 크기만 맞바꾼다.

### C. 한국어 단독 문자열 정리 (진단 3)
- 복습 안내: `Cards you missed come back in review soon` + 한국어 보조.
- 그릇 안내: `bowlHint()`가 `{en, ko}`를 돌려주고 3분기 전부 병기.
