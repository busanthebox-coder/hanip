# 지시 31 — 목차 표면: Shelf 재설계 + 종이 규칙

## 근거
사용자 판정(2026-08-08): "shelf 쪽 탭 디자인이 공책 배경이런것도 별로이긴 한데, A1→챕터별로
디자인도 시인성이 너무 안 좋음." 감독자 실측으로 결함 6건이 확인됐고 시안이 그에 답했다.

- **디자인 스펙 = `docs/design/spec-shelf.html`** (5프레임 + 판단 근거. 코드를 읽으면 치수가 전부 있다)
- **확정: B안(그룹형) 기본 + A안의 두 결정 흡수**
  1. **목표 설명문은 진행 중인 챕터 1행에만** (나머지 챕터는 숨김 — 끝난 과엔 기억이고 안 한 과엔 스포일러다)
  2. **간식은 기본 접힘** — 「Snacks 3 · Survival Help, Family Words…」 한 줄, 탭하면 개별 행으로 펼침
- B안에서 유지: 간식이 챕터 덩어리에 종속(들여쓰기, **구분선 없음**), 구분선은 **챕터 사이에만**,
  챕터 제목 최대 2줄(9과·38과처럼 긴 제목이 잘리지 않게).

## 고칠 결함 6건 (감독자 실측)
1. 괘선이 행 구분선과 선 체계 두 개로 충돌 — 30px 괘선과 62~86px 행은 공약수가 없어 어디서도 안 맞는다
2. 간식이 챕터와 같은 급으로 보인다 — 원인은 크기가 아니라 **`border-top`**(선이 붙는 순간 형제 항목으로 승격)
3. 회색 목표 문장이 챕터마다 2줄을 먹어 제목보다 덩치가 크다
4. 번호는 왼쪽 끝, 진행은 오른쪽 끝이라 한 행을 읽는 데 시선이 왕복한다
5. 완료(도장)·진행중(5/8+바)·미착수(흐린 0/8)의 폭도 형태도 달라 같은 열에서 비교되지 않는다
6. 72과에서 "내가 어디쯤인가"가 없다

## 작업

### A. 종이 규칙 — 표면 3층 (앱 전역 규칙, STYLE.md에 명문화)
| 층 | 재질 | 표면 |
|---|---|---|
| 학습 | 괘선 2겹 + 3px 도트 (현행) | BitePlayer, 문법 레슨, WordDetail, GrammarRefSheet, 읽을거리 **본문**, 가이드 **본문**, 온보딩, 홈 |
| 목차 | **도트만**(괘선 제거) | Shelf, WordbookTab, GrammarCollection, 가이드 인덱스, ReadersShelf, 검색 결과 |
| 시스템 | 없음 | 설정·프로필·전송 시트, 토스트, 탭바 |

판정 기준: **읽고 생각하는 화면이면 괘선 있는 종이, 찾고 고르는 화면이면 괘선 없는 무지,
설정하는 화면이면 종이가 아니다.** 재질을 버리는 게 아니라 같은 종이의 다른 지질을 쓰는 것.
구현은 탭 컨테이너(전체 폭)에 도트 레이어를 깔아 괘선을 덮는다 — 480px 칼럼에 걸면 여백에 괘선이 남는다.
카드 안쪽 `.tooth`는 목차 층에서도 유지.

### B. 챕터 행 (결함 2·3·4·5)
- **왼쪽 거터에 번호와 상태를 붙여 종결**: `[번호 24px][상태 22px]`. 오른쪽 끝은 비운다(chevron은 레벨 헤더에만).
- **상태 3종이 같은 22px 정사각 셀**을 공유: 미착수 = 빈 링 / 진행중 = gold 호 / 완료 = 한입 도장.
  잉크량만 단조 증가시켜 완료가 보상으로 읽히게 하되, 폭·열은 동일하게.
- 정확한 분수(`5/8 bites`)는 72행에 뿌리지 말고 **진행 중인 챕터 행에만** 목표 문장과 함께.
- 간식: `border-top` 제거 + 거터 폭에 맞춘 들여쓰기(54px). 기본 접힘 한 줄, 탭하면 펼침.

### C. 코스 레일 (결함 6)
72눈금 레일(완료 gold, 현재 눈금은 잉크색이며 더 길게) + `Chapter N of 72` + 레벨 스티키 헤더.
레벨 진행은 **bite가 아니라 챕터 단위**로 센다(`11/11 chapters`가 `100/100 bites`보다 위치 감각을 준다).
`buildShelfGroups`가 현재 bite로 세고 있으므로 여기 손댈 때 기존 테스트를 함께 갱신하라.

### D. 다른 목차 표면
단어장·문법 수집에도 종이 규칙과 "같은 급끼리만 구분선을 긋는다"를 적용(스펙 프레임 ⑤ 참조).
