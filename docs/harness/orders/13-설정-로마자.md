# 지시 13 — 설정 시트 + 로마자 정책

## 목표
앱의 모든 스위치가 살 집을 만든다. 이후 지시(소리·햅틱·자동발음·테마·일일목표)가
여기에 항목만 추가하면 되는 구조.

## 작업
1. `src/lib/prefs.js` 신설 — persisted writable 하나(`hanip.prefs-v1`):
   `{ romaja: 'hidden'|'shown', autoSpeak: true, sound: true, haptics: true,
      theme: 'auto'|'light'|'dark', dailyGoal: 1 }` + `setPref(key, value)`.
   기본값은 위 그대로. store.js와 분리 유지(진행 데이터와 취향 데이터는 다른 수명).
2. `SettingsSheet.svelte` 신설 — 홈 우상단 ⚙(44px)으로 여는 바텀시트:
   - 로마자 항상 표시 · Always show romanization (토글)
   - 정답 발음 자동 재생 · Auto-play pronunciation (토글) — 동작은 지시 16에서
   - 효과음 · Sounds / 진동 · Haptics (토글) — 동작은 지시 16
   - 테마 · Theme (자동/밝게/어둡게 세그먼트) — 동작은 지시 17
   - 하루 목표 · Daily goal (1/2/3입 세그먼트) — 그릇 표시는 지시 18
   - 위험 구역: 진행 초기화 · Reset progress (확인 2단계, done/learned/bowls만 삭제,
     prefs는 유지)
   접근성: 시트 열림 시 포커스 이동, ESC/바깥 탭 닫기, 이중 언어.
3. **로마자 정책 전역 적용**: prefs.romaja === 'shown'이면 —
   GuessCard reveal에 발음 즉시 노출("발음 보기" 버튼 생략), HuntCard 줄·ChatCard
   말풍선·PayoffCard에 romanization 서브라인 표시(데이터에 이미 있음), ReaderView·
   클러스터 카드 동일. 'hidden'이면 현행 유지(버튼/탭 공개).
   구현은 각 컴포넌트가 prefs를 구독하는 방식 — 프롭 드릴 금지.

## 검증
```bash
npm run guard:full   # 컴파일 산출 불변 → baseline 그린이어야 정상
```
dev: 설정 열기 → 로마자 켜기 → 한입에서 즉시 발음 노출 확인 → 새로고침 후 유지 →
초기화 → 진행만 사라지고 설정은 유지.
