# 지시 09 (v2) — 단어팩 12 → 간식 한입 · 리더 20 → 책장 읽을거리

v2 갱신: 지시 04·05가 확정한 실제 아키텍처(bites-index·courseData·샤딩)에 맞춤.
BRIEFING-08의 주의보(청크 여유 9kB)를 전제로 한다.

## 목표
부모의 단어팩 12개를 챕터 사이 "간식 한입"으로, 리더 20편을 책장 읽을거리로 이관한다.

## 데이터 (신설 `scripts/extract-extras.mjs` — compile 앞 단계로 package.json에 연결)
1. 부모 사전 로더를 중복 구현하지 마라: `extract-wordbook.mjs`의 `loadDictionary()`를
   `scripts/lib/parentData.mjs`로 추출해 양쪽에서 import (HANIP_PARENT_DATA_DIR 오버라이드
   유지). extract-wordbook 리팩터 후 `npm run guard`로 무회귀 확인부터.
2. 부모 core의 `vocabPacks`(12) → 멤버 entryId를 사전과 조인해 실물 단어
   {hangul, english, romanization, example}로 채워 `data/packs.json`. 조인 실패는 제외하되
   로그에 "N/M members joined" (A1 한자 탭 때 207/212였다 — 90% 미만이면 중단하고 원인).
3. `readers`(20) → 본문·번역·이해질문 그대로 `data/readers.json`.

## 컴파일 (compile-bites.mjs 확장)
- 팩 1개 = kind `snack` 한입 1개: 카드 = guess(팩 단어들, 기존 생성 규칙·금지쌍 재사용)
  → 마지막 payoff 없음, win의 canDo는 팩 goal.
- 출력: **`src/lib/bites-index.json`에 `snacks` 배열 추가**({id, title, afterChapter,
  level: chapterLevel(afterChapter), cardCount}) + 카드 전문은 **새 지연 청크
  `src/lib/snacks.json`** (레벨 파일·단어장 샤드에 얹지 마라 — 주의보 1).
- courseData에 `loadSnackCards(snackId)` 추가 (loadChapterCards와 같은 memoize 패턴).
- **baseline은 chapters만 스냅샷하므로 그린이어야 정상.** 드리프트하면 설계를 어긴 것.

## UI
- 책장: 해당 챕터 행 아래 간식 행(🍪 `간식 · Snack — {제목} · N단어`), 탭 → BitePlayer
  재생. 완료는 기존 done 맵(id `snack-...`)과 그릇 집계 재사용.
- 책장 최하단 `읽을거리 · Readers` 섹션(20편) → 신설 `ReaderView.svelte`:
  문단 단위 "계속 읽기", 번역 토글, QA 플립 (ReadCard의 패턴 재사용, 이중 언어).
- 홈 추천에는 아직 안 끼운다 (지시 11).
