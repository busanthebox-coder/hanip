# 지시 09 — 단어팩 12 → 간식 한입 · 리더 20 → 책장 읽을거리

## 목표
코스 사이사이의 단어팩과 별도 리더를 이관한다. 부모 앱에서 팩은 챕터 사이에, 리더는
별도 서가에 있었다 — 한입에서도 같은 자리다.

## 데이터 추출 (신설 `scripts/extract-extras.mjs`, compile 파이프라인 앞에 연결)
- 부모 `public/data/app-core.*.json`의 `vocabPacks`(12)와 `readers`(20)를 읽는다.
- 팩 멤버는 entryId 참조라 단어 실물이 없다 — 부모 사전 파일들(app-words 등)에서
  entryId→{hangul, english, romanization, examples[0]}을 조인해 `data/packs.json`으로.
  조인 실패 멤버는 카운트만 남기고 제외 (extract 로그에 "N/M members joined").
- 리더는 본문·번역·질문을 그대로 `data/readers.json`으로.

## 컴파일
- 팩 1개 = 간식 한입 1개: kind `snack`, 카드는 기존 guess(추측 우선, 예문 있으면 표시)
  + 마지막에 win. **chapters 배열이 아니라 bites-index의 별도 `snacks` 배열**로 내보내
  A1 기준선(chapters만 스냅샷)과 충돌하지 않게 한다. 각 스낵에 `afterChapter` 번호 포함.

## UI
- 책장: 해당 챕터 행 아래에 간식 카드(작게, 🍪 + "간식 · Snack — 팩 제목 · N단어"),
  탭하면 BitePlayer로 재생(진행 저장은 기존 done 맵 재사용, id `snack-...`).
- 책장 최하단에 `읽을거리 · Readers` 섹션: 리더 목록 → 탭하면 ReadCard 스타일의
  리더 뷰어(문단 단위 계속 읽기 + 번역 토글 + QA 플립). 신규 컴포넌트 `ReaderView.svelte`.
- 홈 다음-한입 추천에는 아직 끼우지 않는다 (지시 11).
