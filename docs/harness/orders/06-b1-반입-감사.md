# 지시 06 — B1 반입·감사 (챕터 35–56)

## 목표
지시 01→02→03에서 확립한 반입→격차→확장→감사 사이클을 B1 22개 챕터에 반복한다.

## 작업
1. 복사: `for n in $(seq 35 56); do cp "../korean-core-starter/scripts/rich-chapters/chapter-$n.json" data/chapters/; done`
2. `npm run compile && node scripts/report-gaps.mjs 35 56`
3. 격차가 새 형태(격식체 어미, 인용 -다고/-냐고, 관형형 등)를 드러내면 **테스트 먼저**
   추출기 보강 — baseline 규율은 지시 02와 동일 (이제 A2 출력도 사실상 준기준선이다:
   보강이 A2 카드를 바꾸면 지시 03의 audit 결론이 유지되는지 해당 챕터만 재확인).
4. `audit-protocol.md`를 35–56에 실행, 수정 정책 동일.

## 검증
```bash
npm run guard:full
ls docs/harness/audit/chapter-{35..56}.json | wc -l   # 22
node -e 'const fs=require("fs");let b=0,t=0;for(let n=35;n<=56;n++){const a=JSON.parse(fs.readFileSync(`docs/harness/audit/chapter-${n}.json`));for(const f of a.findings){t++;if(f.severity==="blocker"&&!f.fixed)b++}}console.log("findings",t,"unfixed blockers",b)'
```

## 완료 기준
- 56챕터 컴파일, guard:full 그린(레벨 청크 b1 예산 내 — 넘으면 b1을 두 파일로 쪼개는
  것까지 이 지시 범위), 미수정 blocker 0, PROGRESS 06행 기록. 배포는 07에서.
