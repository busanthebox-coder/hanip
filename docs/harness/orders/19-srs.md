# 지시 19 — 진짜 SRS: 간격 반복 복습 큐 (페이즈 마감)

## 목표
"워밍업 2장 랜덤"을 망각곡선 위의 진짜 복습으로 바꾼다. 65과를 다 끝낸 사람에게도
앱이 매일 할 일을 준다.

## 설계 (이대로 구현 — 과설계 금지, SM-2 풀버전 아님)
1. `src/lib/srs.js` — 카드 스케줄 맵 `hanip.srs-v1`: key는 단어 ko(guess 계열만.
   문법 카드는 수집/재생 동선이 이미 있다). 값 `{ due, interval, ease? 없음 }`.
   규칙(간격 사다리, 일 단위): 정답 → 다음 칸 [1, 3, 7, 14, 30, 60] (현재 interval의
   다음 값), 오답·몰라요 → 1칸으로 리셋. 신규 학습 시(한입에서 처음 정답) interval 1.
   `dueCards(now)` / `record(ko, correct, now)` / 순수 함수로, 테스트 6+
   (신규/승급/리셋/경계일/빈 맵/미래 due 제외).
2. **기록 연결**: BitePlayer의 guess 해석 경로에서 record 호출(워밍업·본편·간식 모두).
   별표 단어(지시 18)는 리셋 시 interval 1이 아니라 0.5일(당일 재등장) — 저장한
   단어는 더 자주.
3. **워밍업 교체**: warmupCards가 랜덤 대신 due 우선(오래된 순) 2장, due 없으면 현행
   랜덤 폴백. **책장에서 직접 진입한 재생은 워밍업 생략** — BitePlayer에
   `withWarmup=false` 프롭, App의 책장 경로만 false (오늘 루프·한 입 더는 true).
4. **복습 한 입**: due ≥ 6장이면 홈의 오늘 카드 아래 보조 카드
   `복습 한 입 · Review bite — N장 · 2분`: due 상위 8장으로 즉석 한입(kind 'review',
   런타임 생성 — 컴파일 산출 불변). 완료도 그릇 +1. 65과 완주자의 홈은 이 카드가
   주인공이 된다("다 먹었어요" 화면에 복습 잔량 표시).
5. **역방향 카드**: 복습 한입과 워밍업의 카드 중 절반(교대)은 역방향 —
   영어 뜻을 보여주고 한글 3지선다(오답 한글은 learned 풀에서 같은 품사 우선).
   GuessCard에 `direction: 'ko→en'|'en→ko'` 렌더 분기 추가(컴파일 카드엔 direction
   없음 = 기본 ko→en — 산출 불변). 몰라요·발음·별표 동작 동일.
6. **SW 캐시 재점검**(지시 15의 후속): 이 페이즈에서 생긴 신규 정적 자산이 런타임
   캐시 규칙에 걸리는지 확인, 누락이면 finalize-pwa 목록 갱신.

## 검증
```bash
npm run guard:full   # srs 테스트 포함, baseline 여전히 그린
```
dev 시나리오: 한입에서 오답 낸 단어 → 다음날(시간 모킹: srs.js에 now 주입 가능하게)
due 확인 → 복습 한 입 등장 → 역방향 카드 포함 완주 → 그릇 +1 → 책장 직접 진입 시
워밍업 없음 → 오늘 루프에선 due 워밍업.
