# 지시 08 — 책장 레벨 그룹 UI

## 목표
65개 챕터를 한 줄로 늘어놓으면 책장이 스크롤 지옥이 된다. 레벨 아코디언으로 재편한다.

## 작업
1. Shelf.svelte 재구성 (bites-index 기반):
   - 레벨 그룹 5개: `A1 기초 Foundation` `A2 쌓기 Builder` `B1 홀로서기 Independent`
     `B2 정밀 Control` `C1 글말 Written` — 각 헤더에 진행(완료 한입/전체) 배지
   - **학습자의 다음 한입이 속한 레벨만 기본 열림**, 나머지는 탭으로 토글
     (열림 상태는 localStorage `hanip.shelf-open-v1`에 유지)
   - 챕터 행·바이트 목록·재생 동작은 기존 그대로 (onPlay 계약 유지)
2. 검색 입력 추가: 챕터 제목·번호 필터 (단어장 검색과 같은 스타일). 검색 중엔 매칭
   그룹 전부 펼침.
3. 가이드북 카드는 최상단 유지.

## 검증
```bash
npm run guard:full
```
dev로: 신규 사용자(localStorage 삭제) → A1만 열림 / A2 진행 중 상태를 만들고 → A2만
열림 / 검색 "부탁" → 해당 챕터 노출 / C1 챕터 재생 진입.

## 완료 기준
- 5그룹 렌더·기본 열림 규칙·검색 동작, guard:full 그린, PROGRESS 08행 기록
