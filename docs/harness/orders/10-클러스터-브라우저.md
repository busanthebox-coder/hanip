# 지시 10 — 헷갈리는 짝 전집: 표현 클러스터 32세트 브라우저

## 목표
부모의 표현 클러스터 32세트 중 현재 한입에 노출되는 건 단어장 경유 20단어분뿐이다.
전집을 단어장 탭 안의 독립 화면으로 연다.

## 작업
1. `extract-wordbook.mjs` 확장: 부모 core의 `expressionClusters` 32개 전체를
   `src/lib/clusters.json`으로 (기존 cluster 객체와 같은 멤버 형태로 정규화 —
   ContrastCard가 그대로 먹을 수 있게. self는 넣지 않는다).
2. 단어장 목록 상단에 진입 카드: `💡 헷갈리는 짝 전집 · All confusable sets (32)`.
3. 신규 `ClusterBrowser.svelte`: 세트 목록(제목 + 멤버 한글 나열 + 멤버 수) →
   탭하면 ContrastCard 풀 렌더(compact=false). 뒤로가기 2단(목록↔단어장) 일관되게.
   검색(제목·멤버 한글) 하나.
4. clusters.json은 WordbookTab 청크에 얹지 말고 ClusterBrowser에서 dynamic import.

## 검증
```bash
npm run guard:full
node -e 'console.log(require("./src/lib/clusters.json").clusters.length)'   # 32
```
dev로: 전집 진입 → 진짜/정말/참 세트 열람 → 오디오 → 뒤로 2단.

- 32세트 전부 열람 가능, guard:full 그린, PROGRESS 10행 기록
