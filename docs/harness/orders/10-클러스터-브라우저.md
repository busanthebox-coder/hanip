# 지시 10 (v2) — 헷갈리는 짝 전집: 표현 클러스터 32세트 브라우저

v2 갱신: ContrastCard·WordDetail은 이미 실존한다(지시 05에서 확인). 추출 위치와
청크 규율을 현 아키텍처에 맞춤.

## 목표
단어장 경유 48단어분만 보이던 클러스터를 32세트 전집으로 연다.

## 작업
1. **추출**: `extract-wordbook.mjs`는 이미 부모 `expressionClusters`를 로드한다
   (clusterOf 맵). 같은 정규화 형태(멤버 {ko, en, romanization, when, hint, example} —
   self 필드 없이)로 32세트 전체를 `src/lib/clusters.json`에 추가 출력하라.
   기존 단어별 cluster 필드는 그대로 둔다 (WordDetail 무회귀).
2. **진입**: 단어장 목록 상단 카드 `💡 헷갈리는 짝 전집 · All confusable sets (32)`.
3. **화면**: 신설 `ClusterBrowser.svelte` — 세트 목록(제목·멤버 한글 병기·수) →
   ContrastCard 풀 렌더. 검색 1개(제목·멤버 한글) — `SearchField.svelte`가 지시 08에서
   생겼으면 재사용. 뒤로 2단(세트→목록→단어장) 일관.
4. **청크 규율**: clusters.json은 ClusterBrowser에서만 dynamic import.
   WordbookTab 정적 그래프에 들어가면 예산 위반이다 — check-budget이 알려주겠지만
   빌드 출력에서 clusters가 별도 청크인지 눈으로도 확인하라.

## 검증
```bash
npm run guard:full
node -e 'console.log(require("./src/lib/clusters.json").clusters.length)'   # 32
```

기존 짝 카드도 여전히 동작.
