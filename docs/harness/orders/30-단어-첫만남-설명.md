# 지시 30 — 단어 카드: 첫 만남은 설명, 복습은 문제

## 근거
사용자 판정(2026-08-08): "단어 수업이 바로 문장으로 알려주는 게 아니라, 단어 먼저 알려주고 →
문장으로 예시를 들어야 이해하기 편하다."

현재 `GuessCard`는 **문장이 문제지 자체**다(`.stem`에 예문 전체, 목표어는 밑줄). A1 학습자는 아는
단어가 하나도 없는 문장을 먼저 만나므로 문맥 추론이 성립하지 않는다 — 문맥 추론은 주변 어휘를
아는 B1 이후에나 작동하는 기술이다. 선택된 방식: **첫 만남은 설명, 복습은 문제.**

## 설계

### A. 두 가지 모드 (같은 카드, 런타임 분기 — 컴파일 산출 불변)
컴파일된 guess 카드는 그대로 두고 **렌더 모드만 갈린다**. 새 카드 종류·새 데이터·새 저장 필드 금지.

- **첫 만남 = teach 모드**: 그 단어가 SRS 일정에 아직 없을 때(= 처음 보는 단어).
  순서는 사용자 지시 그대로 **단어 → 뜻 → 예문**:
  1. 한국어 단어를 히어로로(현재 리빌의 58px 위계 재사용) + 로마자 + 발음 도트
  2. 영어 뜻(설명은 영어 본문 — 언어 정책)
  3. **예문이 예시로 따라온다** — "이렇게 써요 / Used like this", 문장 안 목표어는 지금처럼 강조,
     영어 번역 동반. 문장이 없는 카드(target null 계열)는 이 단락을 생략한다.
  4. 진행 버튼(정답/오답 없음). 뉘앙스·별표 등 기존 리빌 요소는 유지.
- **복습 = quiz 모드**: 그 단어가 이미 SRS에 있을 때(워밍업·복습 한입·재생 포함) → **현행 동작 그대로**.
  이때는 학습자가 주변 어휘를 아는 상태라 문장 맥락 문제가 제 역할을 한다. 방향 교대(ko→en / en→ko)도 유지.
- 모드 판정은 한 곳(순수 함수)에 두고 테스트로 고정하라. `card.warmup === true`는 항상 quiz.

### B. 바이트가 문제 없이 끝나지 않게 (감독자 판단 — 사용자 확인 필요)
전부 teach로 바꾸면 **단어 한입에 문제가 0개**가 되어, README가 내건 "Nothing is read-only"와
3단계(지시 21~23)가 세운 "한입은 문제로 끝난다"가 무너진다. 그래서 **가장 작은 보정**을 넣는다:

- 단어 한입 끝에 **방금 배운 단어로 만든 확인 문제 최대 2장**을 붙인다(payoff는 그대로 마지막).
- 이 확인 문제는 **런타임에서 그 바이트 자신의 guess 카드를 quiz 모드로 다시 세우는 것**이다 —
  카드 데이터·선택지는 이미 있으므로 컴파일 산출은 변하지 않는다.
- 새 단어가 1개뿐인 바이트는 1장, 0개면 붙이지 않는다.
- 이것은 사용자가 말한 "복습때 문제"의 가장 이른 복습(같은 자리에서의 확인)이다. 사용자가
  "확인 문제도 빼라"고 하면 이 절만 제거하면 되도록 독립적으로 구현하라.

### C. 문안·디자인
`docs/design/STYLE.md`·`docs/tab-contract.md` 준수(영어 메인 + 한국어 소형 보조, 병기 도장 0,
낙차·색 예산·킬 리스트). teach 모드는 새 화면을 발명하지 말고 **현재 리빌 레이아웃을 재배치**하라.

## 게이트
- **컴파일 산출 1바이트 불변** — 시작 전 지문, 종료 후 동일 증명(지시 27~29 관례).
- 테스트 선행. 최소: ①처음 보는 단어 → teach ②SRS에 있는 단어 → quiz ③`warmup:true` → 항상 quiz
  ④재생(이미 배운 바이트) → quiz ⑤확인 문제 0/1/2장 구성 ⑥teach 카드는 정답·오답을 기록하지 않는다
  (SRS·점수·오답 노트에 오염 금지 — 이게 조용히 깨지면 복습 일정이 망가진다).
- `npm run guard:full` 그린. `node scripts/report-density.mjs after-30`으로 **기존 밀도 지표 무회귀** 확인
  (문법 문제 ≥2 비율·1장 바이트 0·중간값). 수치를 보고에 적어라.
- dev QA: ①새 챕터 단어 한입 → 단어→뜻→예문 순서 확인 ②같은 바이트 재생 → quiz로 나오는지
  ③다음 바이트 워밍업 → quiz ④복습 한입 → quiz ⑤확인 문제 2장 + payoff 순서 ⑥다크·라이트.

## 마감
README의 학습 방식 설명 갱신("guess before you're told"의 정확한 범위 — 첫 만남은 설명, 복습이
추측이라는 사실을 정직하게), PROGRESS 30행, 커밋 1개 `[order-30] teach a word first, quiz it on review`.
**푸시·배포 금지**(감독자 몫).

컴파일 산출 불변 · 밀도 무회귀 · guard:full 그린 · QA 6시나리오 기록.
