# 지시 14 — 온보딩 + 시작점 선택

## 목표
첫 실행 30초 안에 두 가지를 해결한다: 이 앱이 뭔지, 그리고 **어디서 시작할지**.
65과짜리 앱이 무조건 1과부터 시작하는 문제를 끝낸다.

## 작업
1. `Onboarding.svelte` 신설 — 첫 실행(진행 0 + 미완료 플래그)에만 전체 화면:
   - 카드 1 "한 입이면 돼요": 3분 한입 콘셉트 한 줄 + 밥그릇 그림
   - 카드 2 "맞히면서 배워요": 추측 우선·무벌점 몰라요 한 줄
   - 카드 3 "어디서 시작할까요? · Where should we start?":
     * 완전 처음이에요 · Brand new → 1과, **prefs.romaja='shown'** 자동
     * 한글은 읽어요 · I can read Hangul → 2과
     * 기초는 해요 · I know the basics → 12과 (A2)
   선택 즉시 시작점 저장(`hanip.prefs-v1`에 startChapter) + 홈으로.
2. `nextBite.js`: done이 비어 있을 때의 탐색 시작점을 startChapter부터로.
   이미 진행이 있으면 startChapter는 무시(현행 순차 유지). **단위 테스트 2+**:
   startChapter=12 신규 사용자 → 12과 1한입 / 진행 있으면 무시.
   주의: 12과 시작 사용자의 워밍업은 learned가 빌 수 있음 — warmupCards가 빈 배열을
   이미 감내하는지 확인(감내함이 정상).
3. 온보딩 재진입 경로: 설정 시트에 "시작점 다시 고르기 · Change starting point".
4. 건너뛰기(우상단, 44px) = 완전 처음 취급.

```bash
npm run guard:full
```

새로고침에도 온보딩 재등장 없음 → 설정에서 시작점 변경 재진입.
