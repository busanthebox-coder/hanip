# 지시 11 (v2) — 홈 오늘-카드 레벨 인지 + 간식 추천 + 이어서

v2 갱신: bites-index의 snacks 배열(지시 09 산출)과 courseData API를 전제로 구체화.

## 목표
65과 시대의 홈: 내 위치(레벨)를 말해주고, 챕터 경계에서 간식을 권하고, 중단 지점을
한 탭에 잇는다.

## 작업
1. **로직 추출이 먼저**: `src/lib/nextBite.js` 신설 —
   `findNext({ index, done, skippedSnacks })` 가 다음 항목
   {type:'bite'|'snack', chapterId?, snackId?, ...} 를 반환. 규칙:
   - 기본은 챕터 순서대로 첫 미완 한입
   - 직전에 끝낸 챕터(모든 한입 done)의 `afterChapter` 간식이 미완이면 **간식 우선**
   - `skippedSnacks`(세션 메모리, 저장 안 함)에 있으면 건너뜀
   단위 테스트 4+: 순차 / 간식 우선 / 간식 스킵 / 전부 완료.
2. Home.svelte: 오늘 카드에 레벨 칩(`A2 · 15과` — chapterLevel 재사용), 간식 추천 시
   문구 `간식 · Snack — 잠깐 단 것 먼저?` + 보조 버튼 `괜찮아요, 다음 과로 · Skip to
   next chapter`(누르면 skippedSnacks에 추가하고 재계산).
3. **이어서**: store에 `lastPlayed {biteOrSnackId, at}` 기록(BitePlayer 진입 시).
   홈에서 미완이면 `이어서 · Continue — {제목}` 칩 → 해당 항목 재생.
4. App.exitBite의 "한 입 더" 롤오버도 nextBite.js를 쓰도록 통일 — 홈과 승리 화면이
   다른 다음-항목을 권하면 버그다.

## 검증
```bash
npm run guard:full   # nextBite 테스트 포함
```
Playwright/dev 시나리오: 챕터 마지막 한입 완주 → 간식 추천 → 스킵 → 다음 과 첫 한입 /
간식 완주 → 그릇 +1 / 앱 재진입 → 이어서 칩.
