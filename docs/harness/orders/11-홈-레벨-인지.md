# 지시 11 — 홈 오늘-카드 레벨 인지 + 간식 추천

## 목표
65과 시대의 홈: 오늘 카드가 내 위치(레벨)를 말해주고, 챕터 경계에서 간식을 권한다.

## 작업
1. 오늘 카드에 레벨 칩 추가: `A2 · 15과` 식 (bites-index의 level 사용).
2. findNext 확장: 다음 한입 탐색 시 **방금 챕터를 끝낸 직후라면** 그 챕터 뒤에 걸린
   간식(snack, 미완료)이 있으면 그걸 먼저 권한다 — 카드 문구
   `간식 · Snack — 잠깐 단 것 먼저?`. 간식을 건너뛰고 다음 챕터로 가는 보조 버튼
   (`괜찮아요, 다음 과로 · Skip to next chapter`)도 제공. 스킵하면 그 간식은 이번
   추천에서 제외(세션 내 기억만, 영구 제외 아님).
3. "이어서" 칩을 실동작으로: store에 `lastPlayed`(biteId·시각) 저장, 홈에서 미완료면
   `이어서 · Continue — {바이트 제목}` 칩 → 탭하면 해당 바이트 재생.
4. 승리 화면 다음-한입 롤오버(App.exitBite)도 같은 findNext 규칙을 쓰게 정리
   (로직을 `src/lib/nextBite.js`로 추출하고 양쪽에서 import — 테스트 3개 이상:
   순차/간식 우선/간식 스킵).

## 검증
```bash
npm run guard:full   # nextBite 테스트 포함
```
dev 시나리오: 11과 마지막 한입 완주 → 간식 추천 확인 → 스킵 → 12과 첫 한입.
