# 지시 12 (v2) — 최종 회귀·배포·릴리스 노트

v2 갱신: 감독자 검증에서 나온 라이브 지연(BRIEFING-08 주의보 2)을 배포 확인 절차로
승격. 총괄 수치의 기준값 제공.

## 목표
이관 완료 선언: 전 게이트 → 배포 → 라이브 해시 일치 확인 → 릴리스 문서.

## 작업
1. `npm run guard:full` — 그린이 아니면 여기서 멈추고 고친다.
2. `scripts/smoke-stats.mjs` 작성·실행: 레벨별 챕터/한입/카드/hunt·teach, 간식·리더·
   클러스터·단어장 수치 총괄표 출력. 참고 기준(지시 07 시점): 65과 · 619한입 ·
   2,039카드 · 단어 718 · 짝 48 — 간식 12개만큼 한입이 늘어 있어야 한다.
3. 감사 총계(현재 기준 발견 232 / blocker 63 / 미수정 0)와 teach 폴백 잔여 목록
   (report-gaps 재실행)을 `docs/harness/RELEASE.md`에.
4. Playwright/dev 최종 시나리오 5: ① 신규 A1 첫 한입 ② A2 무늬 헌트 ③ C1 진입
   ④ 간식→리더→클러스터 ⑤ 이어서 칩. 각 콘솔 에러 0.
5. 루트 `README.md` 갱신: A1-only 문구 제거, 65과·간식·리더·클러스터·단어장 718 반영.
6. **배포와 라이브 검증** (이 순서 그대로):
   ```bash
   npm run deploy
   grep -oE 'assets/index-[^"]+\.js' dist/index.html          # 로컬 엔트리 해시
   # 라이브 해시가 위와 일치할 때까지 20초 간격 재확인 (캐시 우회 쿼리 필수)
   curl -s "https://busanthebox-coder.github.io/hanip/?t=$RANDOM" | grep -oE 'assets/index-[^"]+\.js'
   ```
   일치 후 라이브에서 시나리오 ①·③ 재확인.
7. PROGRESS 전 행 최종화(12행 총괄 수치 포함) + 재스냅샷 이력 표가 실제 이력과
   일치하는지 마지막 점검. RELEASE.md에 알려진 한계(teach 폴백 목록, polish 미수정 수,
   간식 조인 제외 멤버 수) 정직하게.

## 완료 기준
- guard:full 그린 · **라이브 엔트리 해시 = 로컬 dist 해시** · 라이브 65과+간식+리더
- RELEASE.md 존재 · PROGRESS 전 행 ✅ · 이관 종료 선언
