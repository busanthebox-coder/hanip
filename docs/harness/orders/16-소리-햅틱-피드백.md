# 지시 16 — 소리·햅틱·정답 피드백 통일

## 목표
정답의 순간에 몸이 반응하게 한다: 소리 + 진동 + 자동 발음. 그리고 오답 재출제의
예고를 카드 전 종류에서 통일한다.

## 작업
1. `src/lib/feedback.js` 신설 — **오디오 파일 없이 WebAudio 합성**:
   - `tick()` 정답: 나무 탭 느낌 (사인+빠른 감쇠, ~880Hz, 80ms)
   - `thud()` 오답: 낮고 짧게 (~180Hz, 120ms) — 벌점처럼 크지 않게
   - `fanfare()` 한입 완료: 3음 상행 아르페지오 250ms
   - `buzz(ms)` 햅틱: `navigator.vibrate` 가드 호출 (정답 15ms, 오답 [30,40,30])
   전부 prefs.sound/haptics 확인 후 실행. AudioContext는 첫 사용자 제스처에서 lazy
   생성(iOS 자동재생 정책). 단위 테스트: prefs off 시 no-op 확인(모킹).
2. **연결점** (카드 컴포넌트의 onResolve 경로에 이미 correct가 흐른다):
   guess/drill/order 정답→tick+buzz, 오답→thud+buzz, 헌트 완성→tick, win 화면→fanfare.
3. **자동 발음**: prefs.autoSpeak면 — guess reveal 순간 `speak(word.ko)`,
   payoff 카드 등장 시 `speak(line.ko)`, 클러스터/단어장 상세는 현행 수동 유지.
   효과음과 겹칠 때 발음이 60ms 뒤에 오도록 (tick 먼저, 말이 그 위에).
4. **재출제 예고 통일**: 오답 reveal에 공통 칩 `3장 뒤에 다시 나와요 · You'll see this
   again` (guess·drill·order 동일 문구), 재출제로 돌아온 카드 상단에
   `다시 · Again` 칩. BitePlayer가 requeued 플래그를 이미 갖고 있다.
5. **reveal 가시성**: 정답 후 reveal이 화면 밖이면 `scrollIntoView({block:'nearest'})`.

## 검증
```bash
npm run guard:full
```
dev: 정답 톡+진동(모바일) → 자동 발음 → 설정에서 소리 끄면 전부 무음 →
오답 → 예고 칩 → 3장 뒤 "다시" 칩 확인 → 한입 완료 팡파르.

## 완료 기준
- 4종 피드백 + 자동 발음 + 예고 통일, 전부 설정으로 차단 가능
- guard:full 그린(컴파일 산출 불변), PROGRESS 16행 기록
