# 지시 07 — B2·C1 반입·감사 (챕터 57–65), 전 코스 배포

## 목표
마지막 9개 챕터(B2 57–63, C1 64–65)를 들여와 감사까지 마치고, **65과 전체를 배포**한다.

## 작업
1. 복사: `for n in $(seq 57 65); do cp "../korean-core-starter/scripts/rich-chapters/chapter-$n.json" data/chapters/; done`
2. `npm run compile && node scripts/report-gaps.mjs 57 65`
3. B2·C1 특이사항 — 미리 알려진 것:
   - ch-57 사동 접미사(`-이/히/리/기/우/구/추-`), ch-63 문어체 어미: 형태소 추출이
     안 되면 **teach 폴백이 정답**이다. 무리하게 헌트를 만들지 마라.
   - ch-63/65는 문어·격식 텍스트라 대화 바이트가 다른 형태일 수 있다 — 빌더가 없는
     섹션은 조용히 건너뛰는 게 현재 계약. 빈 바이트만 안 나오면 된다(validate가 잡음).
4. 감사 57–65 (9챕터), 정책 동일.
5. 단어장·클러스터 수치가 최종치가 된다 — extract 로그의 수치를 PROGRESS에 옮겨 적어라.

## 검증
```bash
npm run guard:full
ls data/chapters | wc -l   # 65
ls docs/harness/audit/chapter-*.json | wc -l   # 54 (12–65)
```
